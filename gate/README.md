# PayoutFit winner-gap package

Evidence for the mid-stage gate in `igoreduardoai/hackathon-lab` (`judge_stack`, branch `cursor/winner-gap-gate-v2-ad0f`). The checker is not copied into this repo.

```bash
python3 -m judge_stack gate --stage mid --package gate
```

Run that from a checkout of the lab repo, with this `gate/` directory as the package. Checked boxes mirror files that passed. A box does not create a pass.

Items that need a person, a gallery, a hosted URL, or someone outside this repo stay failed. The notes in those files say what is missing.
